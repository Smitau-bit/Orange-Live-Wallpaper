How to install:

FOR GOOGLE PIXEL:

1. Go to your home screen
2. Long-press the screen until appears some options
3. Select that option that says wallpaper
4. Select "Live Wallpaper"
5. Look for "Orange Live Wallpaper"
6. Select as wallpaper

FOR OTHER PHONES LIKE: SAMSUNG, REDMI, OPPO, ETC.:

1.Go to Play Store
2.Search for Google Wallpaper
3.Install it and open in the app
4.Select "Live Wallpaper"
5.Look for "Orange Live Wallpaper"
6.Select as wallpaper

NOTE:The resolution is for old devices with 1440x2560 or older. Is working for Android 7.1 up to Android 17!
